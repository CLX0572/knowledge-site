# 匀变速直线运动的研究

## 一、实验：探究小车速度随时间变化的规律

- 打点计时器（电磁、电火花）、$T=0.02\,\text{s}$（50Hz）
- 纸带处理：逐差法求加速度

## 二、速度与时间的关系

$$v = v_0 + at$$

- $v-t$ 图像：斜率为 $a$，面积为位移 $x$

## 三、位移与时间的关系

$$x = v_0 t + \frac{1}{2} a t^2$$

- 推导：用 $v-t$ 图像面积法

## 四、自由落体运动

- 条件：只受重力、初速为 0
- 初速度为零的匀加速直线运动

$$v = gt, \quad h = \frac{1}{2} g t^2, \quad v^2 = 2gh$$

- $g \approx 9.8\,\text{m/s}^2$（随纬度升高增大，随高度升高减小）

## 五、常用推论

$$v^2 - v_0^2 = 2ax$$

- 中间时刻速度 = 平均速度：$v_{t/2} = \bar{v} = \frac{v_0 + v}{2}$
- 连续相等时间 $T$ 内位移差：$\Delta x = aT^2$
