## 🧠 知识点板块（4 层递进 · 共 3 小节）

### 1. §5.1 认识传感器

#### 1.1-课本定义

> **传感器**：能像人的感觉器官（眼/耳/鼻/舌/皮肤）一样，**感受被测量**（力/温度/光/声/磁/湿等物理量），并按一定规律把它们**转换成可用信号**（通常是电信号）的器件或装置，叫传感器。
>
> 一般由三部分组成：**敏感元件**（直接感受被测量，例：热敏电阻感受温度）→ **转换元件**（把敏感输出转成电信号，例：应变片形变→电阻变化）→ **转换电路**（放大/滤波/模数转换，把信号转成方便处理的标准电信号，例：0~5V 或 4~20mA）。
>
> 分类（按被测量）：物理传感器（力/热/光/电/磁/声/湿）、化学传感器（气/离子/湿度 pH）、生物传感器（酶/免疫/DNA/细胞）。

#### 1.2-常规理解

- 一句话理解：**传感器 = 电五官**，把人类五官不能直接变成电信号的量（温度、压力、湿度、光照、磁场……）全部转成电压/电流，交给 MCU/单片机/电脑处理。
- 典型考法 1：判断生活实例是不是传感器？例：电子秤（力→电 ✓）；普通温度计（热→液柱高，没转电 ❌）；数码相机 CCD 芯片（光→电 ✓）
- 典型考法 2：三部分辨别？例：霍尔元件本身=转换元件；贴在霍尔元件上的导磁片=敏感元件；运放电路=转换电路
- ⚠️ 易错：传感器**只能输出信号，不能直接驱动大功率负载**——必须后面接继电器/三极管/MOS 管/接触器才能动电机/开空调

#### 1.3-进阶理解

- 本质：**「非电学量 → 电学量」的映射函数** $V_{out} = f(x)$，x 是被测量（温度/力/位移…），理想 f 是线性的，但实际会有非线性、零点漂移、温漂、迟滞（hysteresis）——这些决定传感器精度等级。
- 传感器主要性能指标：**量程**（能测范围）、**精度**（误差±%FS 满量程）、**分辨率**（能分辨的最小变化量，例：12 位 ADC 0~5V = 5V/4096 ≈ 1.2mV 分辨率）、**响应时间**（阶跃输入到 90% 稳定值时间）、**重复性**（同条件多次测量偏差）
- 跨学科：和数字电路/单片机（Arduino/STM32）连接 → 模数转换 ADC（模拟量→数字量）+ 数模转换 DAC（数字→模拟）+ 通信协议（I²C/SPI/UART/Modbus）

#### 1.4-额外数理知识

- 误差传递：如果传感器输出 $y = kx + b$，k 误差 Δk%，零点 b 误差 Δb，x 真实误差 = Δy/k - yΔk/k² → 所以先**校准**（2 点校准消 b 和 k 误差）再用比直接读值准 1~2 个数量级
- 微积分：低通滤波电路 RC = 时间常数 τ，时域阶跃响应 $V_{out}(t) = V_{in}(1-e^{-t/τ})$；频域截止频率 $f_c = 1/(2πRC)$。用来滤除传感器 50Hz 工频干扰和高频噪声
- 竞赛/强基：**惠斯通电桥**精确测电阻变化 + **差分放大电路**（仪表放大器 INA128，共模抑制比 CMRR 120dB）+ 温度补偿（并联负温度系数热敏抵消温漂）
- 历史趣闻：1856 年汤姆逊（开尔文勋爵）发现**应变效应**（金属丝受拉伸电阻增大）→ 1938 年第一个箔式电阻应变片诞生 → 现代电子秤/加速度计/压力传感器的鼻祖

### 题型五 · 学生实验专题

> 🔗 对应锚点：[[index#⚗️-高中必做学生实验2019-课标-共-9-项-选做|高中实验· 传感器实验]] + [[传感器#3.1-课本定义|§5.3 制作自动控制装置]]
>
> 实验① 自制温控报警（80°C 超温声光报警）
> ① 目的：用 NTC 热敏 + LM393 + 继电器 + 蜂鸣器制作超温报警器
> ② 原理：温度 T↑ → R_NTC↓ → 比较器反相输入端电压 V-↓ → 当 V- < V+（电位器设阈值 80°C）→ 输出高电平 → 三极管 8050 导通 → 继电器吸合 → 蜂鸣器响 + LED 红亮
> ③ 器材：面包板、NTC-MF52 10K@25°C、电位器 10K、LM393、9013 NPN、5V 继电器、无源蜂鸣器、LED 红/绿、5V 电源、杜邦线若干、热风枪/热水杯（做温度源）、温度计（校准）
> ④ 关键步骤（得分句★）：
> （1）**★先校准 NTC：用热水+温度计测 3 组（T，R），半对数坐标 lnR - 1/T 线性拟合求 B 常数**
> （2）**★阈值设置：80°C 对应计算出的理论 R → 电位器调 V+=V-，临界点继电器刚吸合**
> （3）……至少 6 步
> ⑤ 数据表格：T(°C) 25/50/60/70/80/90 | R_NTC(kΩ) 实测 | V-(V) 实测 | 继电器状态 吸合/释放
> ⑥ 图像：半对数坐标 lnR - 1/(T+273.15) 图，**斜率 k = B（材料常数）**，截距 = lnR₀
> ⑦ 误差来源：1. 温度计读数 ±1°C → R 误差 ±3%（因为指数关系！B=3950K 每 1°C 约 3~4% 电阻变化）→ 系统误差 改进：用 DS18B20 数字温度传感器（±0.5°C）替代模拟 NTC 2. 继电器机械抖动 10ms 触点弹跳 → 改进：输出加 104 独石电容消抖 或 加 50ms 软件消抖延时 3. 比较器 LM393 输入失调电压 ±2mV → V- < V+ 临界点 ±0.2°C 模糊区 4. 室温漂移……
> ⑧ 改进方法：换 Arduino Nano + DS18B20 + OLED 屏 + 按键设阈值温度，软件 PID 加热（SSR 固态继电器）→ 10L 水恒温 80±0.1°C，进阶版恒温箱/煮糖器/Sous vide
> ⑨ 变式 3 种：变式 1 光控（换成光敏电阻+比较器，晚上灯自动亮）/ 变式 2 土壤湿度自动浇水（湿度传感器+水泵）/ 变式 3 人体红外 PIR + 超声波测距 + 语音播报=智能导盲杖
