# 电磁振荡与电磁波

## 一、电磁振荡

- LC 电路：
  $$T = 2\pi\sqrt{LC}$$
- 周期振荡：电场能 ↔ 磁场能
- 阻尼振荡（自由振荡）与无阻尼振荡（受迫振荡）

## 二、电磁波的发射和接收

- 发射条件：频率足够高 + 开放电路
- 调制：调幅 AM（改变振幅）、调频 FM（改变频率）
- 接收：调谐（选台，选共振 $f = \frac{1}{2\pi\sqrt{LC}}$）→ 解调（取出信号）

## 三、电磁波谱

按波长由大到小（频率由低到高）：

| 波段 | 产生 | 主要应用 |
|------|------|---------|
| 无线电波 | 振荡电路 | 广播、雷达、通信 |
| 微波 | 振荡电路 | 微波炉、WiFi、移动通信 |
| 红外线 | 分子热振动 | 遥控、夜视、加热 |
| 可见光 | 原子外层电子跃迁 | 视觉、光学仪器 |
| 紫外线 | 原子外层电子跃迁 | 杀菌、防伪、荧光 |
| X 射线 | 原子内层电子跃迁 | 透视、CT、安检 |
| γ 射线 | 原子核衰变 | 放疗、探伤 |
