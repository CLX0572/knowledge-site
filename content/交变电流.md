# 交变电流

## 一、交变电流

- 定义：大小和方向随时间做周期性变化的电流
- 产生：矩形线圈在匀强磁场中绕垂直于 $B$ 的轴匀速转动
- 瞬时值：
  $$e = E_m \sin\omega t$$
  峰值：
  $$E_m = NBS\omega$$

## 二、描述交变电流的物理量

- 周期 $T$、频率 $f$、$\omega = \frac{2\pi}{T} = 2\pi f$
- 峰值/最大值：$U_m、I_m$
- **有效值**（与交流热效应等效的直流值）：
  $$U = \frac{U_m}{\sqrt{2}},\quad I = \frac{I_m}{\sqrt{2}}$$
  （$U/I$ 电表读的就是有效值；家用 220V = 有效值，峰值 ~311V）
- 平均值：用于求通过的电量 $q = \bar{I}\cdot\Delta t = n\frac{\Delta \Phi}{R_\text{总}}$

## 三、变压器

- 原理：互感
- 电压比：

$$\frac{U_1}{U_2} = \frac{n_1}{n_2}$$

- 电流比（理想单副线圈）：
  $$\frac{I_1}{I_2} = \frac{n_2}{n_1}$$
- 理想：$P_1 = P_2$

## 四、远距离输电

- 输电线功率损失：$P_\text{损} = I^2 R = \left(\frac{P}{U}\right)^2 R$
- 提高输电电压 → 大幅减小损失
- 三级：升压变压→高压送电→降压变压→用户
