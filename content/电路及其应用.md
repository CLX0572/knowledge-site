# 电路及其应用

## 一、电源和电流

- **电流**：$I = \frac{q}{t}$，微观 $I = nqSv$
- **电源**：将其他形式能→电能，维持电势差
- **电动势**：$E$，电源开路两端电压数值上等于电动势

## 二、导体的电阻

$$R = \rho\frac{L}{S}$$

- 电阻率 $\rho$：与材料和温度有关；金属随 $T$ 升高增大，半导体减小
- 超导：温度低于临界温度时 $\rho=0$

## 三、串联和并联

- **串联**：
  - $I = I_1 = I_2 = \cdots$
  - $U = U_1 + U_2 + \cdots$
  - $R = R_1 + R_2 + \cdots$
  - 分压：$U_1/U_2 = R_1/R_2$
- **并联**：
  - $I = I_1 + I_2 + \cdots$
  - $U = U_1 = U_2 = \cdots$
  - $\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots$
  - 分流：$I_1/I_2 = R_2/R_1$
- 伏安法测电阻：内接外接误差分析

## 四、焦耳定律

$$Q = I^2 R t$$

- 电功 $W = UIt$；纯电阻 $W = Q$；非纯电阻 $W > Q$（电机、电解槽）
- 功率：$P = UI$（通用）；$P = I^2 R = \frac{U^2}{R}$（纯电阻）

## 五、闭合电路欧姆定律

$$I = \frac{E}{R + r}, \quad U_\text{外} = E - Ir$$

- 短路：$R=0$，$I = E/r$
- 开路：$I=0$，$U_\text{端} = E$
- 电源输出功率 $P = I^2 R = \frac{E^2 R}{(R+r)^2}$，当 $R=r$ 时 $P_\text{max} = \frac{E^2}{4r}$
- 路端电压随外阻变化曲线
