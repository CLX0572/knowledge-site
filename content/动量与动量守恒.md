# 动量与动量守恒

## 一、动量和动量定理

- **动量**：$\vec{p} = m\vec{v}$，矢量，方向同 $v$
- **冲量**：$\vec{I} = \vec{F}\Delta t$（恒力）
- **动量定理**：合外力冲量 = 动量变化

$$\vec{I}_\text{合} = \Delta \vec{p} = \vec{p}_2 - \vec{p}_1$$

## 二、动量守恒定律

- **条件**：系统所受合外力为零（或某一方向合外力为零→该方向守恒；或内力远大于外力近似守恒）
- 表达式：

$$m_1\vec{v}_1 + m_2\vec{v}_2 = m_1\vec{v}_1' + m_2\vec{v}_2'$$

## 三、实验：验证动量守恒定律

- 气垫导轨 + 光电门
- 斜槽末端平抛 + 落点动量分析（$mv = m\frac{x}{t}$，$t$ 相同→可用 $x$ 代替 $v$）

## 四、弹性碰撞与非弹性碰撞

| 类型 | 动量 | 机械能 |
|------|------|--------|
| 弹性碰撞 | 守恒 | 守恒 |
| 非弹性碰撞 | 守恒 | 有损失 |
| 完全非弹性碰撞 | 守恒 | 损失最大（碰后共速）|

- 弹性一维碰撞：$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$，$\tfrac{1}{2}m_1v_1^2+\tfrac{1}{2}m_2v_2^2=\tfrac{1}{2}m_1v_1'^2+\tfrac{1}{2}m_2v_2'^2$
- 推导得：$v_1' = \frac{(m_1-m_2)v_1+2m_2v_2}{m_1+m_2}$；$v_2'=\frac{(m_2-m_1)v_2+2m_1v_1}{m_1+m_2}$
- $m_1=m_2$ 时 $v_1'=v_2, v_2'=v_1$，即交换速度

## 五、反冲 火箭

- 反冲：动量守恒（内力远大于外力）
- 火箭：$v = u\ln\frac{M}{m}$（齐奥尔科夫斯基公式，$u$ 喷射速度，$M/m$ 质量比）
