# 浮力

## 一、浮力

- 定义：浸在液体（或气体）中的物体受到向上的力
- 方向：竖直向上
- 产生原因：上下表面压力差

## 二、阿基米德原理

$$F_\text{浮} = G_\text{排} = \rho_\text{液} g V_\text{排}$$

- 浸在液体中的物体受到的浮力 = 排开液体所受的重力

## 三、物体的浮沉条件及应用

| 关系              | 状态                               |
| ----------------- | ---------------------------------- |
| $F_\text{浮} > G$ | 上浮 → 最终漂浮（$F_\text{浮}=G$） |
| $F_\text{浮} = G$ | 悬浮                               |
| $F_\text{浮} < G$ | 下沉 → 最终沉底                    |

- 应用：轮船、潜水艇、气球和飞艇、密度计
