# 牛顿运动定律

牛顿运动定律是经典力学的基石，描述了物体运动与所受力的关系。

## 牛顿第一定律（惯性定律）

一切物体在没有受到外力作用时，总保持静止状态或匀速直线运动状态。

$$\vec{F}_{\text{合}} = 0 \Rightarrow \vec{v} = \text{常量}$$

## 牛顿第二定律

物体的加速度与所受合外力成正比，与质量成反比。

$$\vec{F} = m\vec{a}$$

分量形式：

$$F_x = ma_x, \quad F_y = ma_y$$

## 牛顿第三定律

两个物体之间的作用力和反作用力总是大小相等、方向相反，作用在同一条直线上。

$$\vec{F}_{12} = -\vec{F}_{21}$$
