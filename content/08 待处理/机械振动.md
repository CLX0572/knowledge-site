# 机械振动

## 一、简谐运动

- 定义：回复力 $F = -kx$（线性回复力）
- 位移：$x = A\sin(\omega t + \varphi)$（或余弦）
- 参量：振幅 $A$、周期 $T$、频率 $f = 1/T$、角频率 $\omega = 2\pi f$

## 二、简谐运动的描述

- $x-t$ 图像：正弦（余弦）曲线
- 速度：$v = x' = A\omega\cos(\omega t + \varphi)$
- 加速度：$a = v' = -A\omega^2\sin(\omega t + \varphi) = -\omega^2 x$
- 能量：$E = \frac{1}{2}kA^2 = \frac{1}{2}kx^2 + \frac{1}{2}mv^2$（守恒，无阻尼）

## 三、简谐运动的回复力和能量

- 回复力来源：弹簧弹力 / 重力分量（单摆小角度 $\sin\theta \approx \theta$）

## 四、单摆

$$T = 2\pi\sqrt{\frac{L}{g}}$$

- 条件：最大摆角 $\theta < 5^\circ$
- $T$ 只与 $L$ 和 $g$ 有关，与振幅、摆球质量无关

## 五、实验：用单摆测量重力加速度

- 测 $L$（摆线长 + 小球半径），测 $T$（多次测 $n$ 次全振动时间除以 $n$）
- $g = 4\pi^2 L / T^2$

## 六、受迫振动 共振

- 阻尼振动：振幅逐渐减小
- 受迫振动：驱动力作用下，稳定后频率 = 驱动力频率
- **共振**：$f_\text{驱} = f_\text{固}$ 时振幅最大
  - 防止共振：改变固有频率 / 改变驱动力频率
